# Scanner Installer

Автоматическая установка **Scanner 2.13** (Disk Space Analyzer) в Windows с интеграцией в контекстное меню проводника.

## 📋 Описание

Scanner - это портативная утилита для анализа дискового пространства с визуализацией структуры папок. Данный установщик автоматизирует процесс развертывания программы в системе.

**Что делает установщик:**
- Копирует Scanner в `C:\Program Files\Scanner`
- Создает ярлык в меню Пуск
- Добавляет пункт "Show Usage with Scanner" в контекстное меню папок
- Добавляет пункт "Show Usage with Scanner" в контекстное меню дисков

## 🚀 Использование

### Установка

1. Скачайте репозиторий
2. Убедитесь, что структура файлов выглядит так:
```
Scanner_Installer/
├── install_Scanner.bat
└── Scanner/
    ├── Scanner.exe
    └── (остальные файлы программы)
```
3. Запустите `install_Scanner.bat` **от имени администратора**
4. Следуйте инструкциям на экране

### После установки

**Запуск из меню Пуск:**
- Найдите "Scanner" в меню Пуск

**Запуск из контекстного меню:**
- Нажмите ПКМ на любой папке → "Show Usage with Scanner"
- Нажмите ПКМ на любом диске → "Show Usage with Scanner"

## 📦 Требования

- Windows 10/11 (или Windows 7/8 с поддержкой PowerShell)
- Права администратора для установки
- Scanner 2.13 (включен в репозиторий)

## 🔧 Технические детали

Установщик выполняет следующие операции:
- Проверка прав администратора
- Копирование файлов через `xcopy`
- Создание ярлыка через PowerShell
- Добавление записей в реестр для контекстного меню:
  - `HKCR\Directory\shell\Scan_Content`
  - `HKCR\Drive\shell\Scan_Content`

## ⚠️ Примечания

- Скрипт требует запуска от имени администратора
- При повторной установке существующие файлы будут перезаписаны
- Для удаления программы используйте стандартное удаление папки и очистите записи реестра

## 🛠️ Удаление

Для полного удаления Scanner:

1. Удалите папку `C:\Program Files\Scanner`
2. Удалите ярлык из меню Пуск
3. Удалите записи реестра:
```batch
reg delete "HKCR\Directory\shell\Scan_Content" /f
reg delete "HKCR\Drive\shell\Scan_Content" /f
```
